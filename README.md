## Project Abstract
Campus Ride Share is a web application for Southeast Missouri State University students who want to find other students traveling to similar locations. Users will be able to create a ride request or ride-offer post with basic trip details, such as destination, date, available seats, and contact information. They will also be able to browse and filter posts to locate possible carpool opportunities. To keep the project manageable for a two-person team, the first version will not include payments, GPS tracking, real-time messaging, or automatic ride matching.
